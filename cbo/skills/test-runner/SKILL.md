# test-runner

テストパスに指定したテストファイルまたはディレクトリのテストを実行するスキルです。

## コンテキスト

- テストパス: $ARGUMENTS
- カバレッジ: $ARGUMENTS に `--coverage` が含まれる場合に取得する

## タスク

出力する場合はリストとして装飾を省いて出力します。

0. テストパスが指定されていない場合はユーザーにその旨を通知し終了します
1. `run-test.ts` を実行しテスト結果を取得
2. 全てのテストが成功した場合、テストファイル、テストケース、実行時間を出力して終了
3. いずれかのテストが失敗した場合、失敗したテストのみを全て表示して終了
4. `--coverage` が指定されている場合、テスト結果に続けて vitest が出力したカバレッジのテキスト表をそのまま出力します（要約・省略・フィルタは行わない）

## カバレッジ取得の禁止事項

- 全テストのカバレッジ取得は禁止です。時間がかかりすぎるため実行してはいけません。
- `.` やプロジェクトルート、`pages/`・`components/`・`composables/` のような上位階層ディレクトリを対象にしたカバレッジ取得も禁止です。スクリプト側でもルート相当のパスは拒否されます。
- 許可されるのはテストファイル単位、または機能単位の末端ディレクトリのみです。
- 広範な対象でのカバレッジを求められた場合は実行せず、対象を絞るようユーザーに求めて終了します。

## `run-test.ts` の実行方法

```bash
bun run "${CLAUDE_SKILL_DIR}/scripts/run-test.ts" <テストパス...> [--coverage]
```

- `<テストパス...>` (必須): テスト対象のファイルまたはディレクトリのパスを1つ以上。空白区切りで複数指定できます
- `--coverage` (任意): カバレッジを取得し、テキスト表として標準出力に出力します。いずれかにルート相当のパスを指定した場合はエラーになります
- テストパスを指定せずに実行するとエラーになります
- 全テストの実行は非常に時間がかかるため、必ず対象を絞って実行してください
