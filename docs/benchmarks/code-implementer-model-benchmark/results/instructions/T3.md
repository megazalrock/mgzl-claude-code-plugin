# ホワイトボードの日付選択をカレンダーと共通のヘッダー日付カルーセルに統一する

## 背景

カレンダー（月・週）・稼働表のヘッダーには共通の日付カルーセル（`ScheduleHeader` 配下の `DateControl`）が表示されているが、ホワイトボード（分割・連結・日)はボード内部の独自日付ナビゲーションで日付を移動しており、UI が統一されていない。ホワイトボードの日付選択もヘッダーの日付カルーセルへ一本化したい。

## 要件

### ホワイトボード（分割・連結）

1. ヘッダーに日付カルーセルを表示し、前後ボタンで表示期間が移動すること
2. 「今月」ボタンで今日を含む期間に戻ること
3. ボード内部の旧日付ナビゲーションを表示しない（削除する）こと
4. SP でも同様に動作すること

### ホワイトボード（日）

5. 日付テキストは「yyyy年MM月dd日」形式で表示し、前後ボタンで 1 日ずつ移動すること
6. 「今日」ボタンで今日に戻ること
7. カレンダーポップアップから表示中と同じ日を選択したときは再取得が走らないこと（同日判定）
8. 休日の日は休日テキスト行が表示され、現在時刻のポインタ・バーの位置が非休日時・非消耗品タブと比べてズレないこと

### 既存画面（カレンダー・稼働表）

9. カレンダー（月・週）・稼働表の日付カルーセルの表示・前後移動・「今月 / 今週」ボタンが従来どおり動作すること（デグレ禁止）
10. 【仕様変更】日付カルーセルの日付テキストは PC / SP 共通で「yyyy年MM月」（ゼロ埋め）形式に統一する（従来は PC「yyyy年M月」・SP「M月」。カレンダー・稼働表にも適用される表示上の仕様変更）

### SP のフィルター

11. SP 表示で各スケジュール画面のフィルターボタンからフィルターモーダルが開き、フィルター条件設定時にボタンが緑色になること（デグレ禁止）

## 対象範囲

- スケジュールヘッダー関連コンポーネント（`components/organisms/Schedule/ScheduleHeader/` 配下）
- ホワイトボード関連コンポーネント（`components/organisms/Schedule/Gantt/` 配下）
- ホワイトボードのページ（`pages/schedules/gantt/` 配下）

## 補足

- 表示形式の変更（要件 10）により既存テストの期待値調整が必要になる場合は、当該テストケースのみの最小修正に留め、報告に明記すること
- テストコードの新規追加は本タスクの範囲外（test-implementer が別途担当）。既存テストの回帰チェックは通すこと
