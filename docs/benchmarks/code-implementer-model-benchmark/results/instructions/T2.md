# 稼働表の画面外セルのスケジュールカードを描画対象から外して描画負荷を軽減する

## 背景

稼働表（`/schedules/shift_board`）は行 × 日付 × シフト枠のセル数が多く、全セルのスケジュールカードを常時マウントすると DOM 量が膨らみ描画負荷が高くなる。画面外のセルのカードを描画対象から外して描画負荷を軽減したい。

あわせて、稼働表をスクロールするとホバー中のツールチップが表示され続ける既知の問題があるため、これも修正する。

## 要件

### 画面外セルのアンロード

1. 画面外にあるセルのスケジュールカードをアンマウントし、DOM 量を削減する
2. セルが画面内に戻ったら、スケジュールカードを元通り表示する
3. カードをアンマウントしても行・セルの高さが変わらず、スクロール中にガタつき（レイアウトシフト）が発生しないこと
4. ローディング中は祖先要素が非表示（`display: none`）になるが、この状態を「画面外」と誤認してカードを消してしまわないこと（ローディング完了後に表示が崩れないこと）
5. フィルター・月切替等でデータが入れ替わっても、古い状態（以前の高さのままの空セル等）を持ち越さないこと
6. 初期表示・スケジュールカードのホバー（ツールチップ表示）・クリック（詳細モーダル表示）は従来どおり動作すること（デグレ禁止）

### スクロール時のツールチップ非表示

7. スケジュールカードにホバーしてツールチップを表示したまま稼働表を縦横にスクロールしたとき、ツールチップが非表示になること

## 対象範囲

- 稼働表関連コンポーネント（`components/organisms/Schedule/ShiftBoard/` 配下）

## 補足

- パフォーマンス改善が目的のため、改善策自体が新たな描画負荷・メモリリークを生まないよう留意すること
- テストコードの新規追加は本タスクの範囲外（test-implementer が別途担当）。既存テストの回帰チェックは通すこと
