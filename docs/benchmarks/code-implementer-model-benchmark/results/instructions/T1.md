# 手配表スケジュールカードのホバー時にスケジュールの備考をツールチップで表示する

## 背景

手配表（週・日）のスケジュールカードは、タイトルにホバーした際に素の `v-tooltip` でタイトル文字列のみを表示している。ホワイトボード等の他画面のスケジュールカードでは共通コンポーネント `ScheduleTooltip` が使われており、スケジュールに登録されている備考（メモ）もツールチップ内で確認できる。手配表でも同様に備考を確認できるようにしたい。

## 要件

1. 手配表（週・日）のスケジュールカードのタイトルホバー時のツールチップを、共通コンポーネント `ScheduleTooltip` に統一する
2. 備考が入力されているスケジュールは、ツールチップ内にスケジュールタイトルと備考の内容を表示する（備考が複数行・長文の場合も適切に表示されること）
3. 備考が未入力のスケジュールは、ツールチップにタイトルのみを表示し、備考欄は表示しない
4. `is_visible_detail` が `false` のスケジュール（権限等で詳細非表示）は、ツールチップに「予定あり」を表示する（ホワイトボード等の既存挙動と一致させる）
5. スケジュールカードのタイトルクリックでスケジュール詳細モーダルが従来どおり開くこと（デグレ禁止）
6. 手配表の祝日スケジュールカードの表示・操作が従来どおり動作すること（デグレ禁止）

## 対象範囲

- 手配表のスケジュールカード関連コンポーネント（`components/organisms/Schedule/AssignBoard/AssignBoardContent/ScheduleCard/` 配下）

## 補足

- テストコードの新規追加は本タスクの範囲外（test-implementer が別途担当）。既存テストの回帰チェックは通すこと
